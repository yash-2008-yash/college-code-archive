# Experiment 11.1 - Bank Transaction System (Multithreading)

Write a Java program that demonstrates the creation and execution of multiple threads by implementing a Bank Transaction System. A bank wants to simulate multiple transactions happening concurrently in a system. Each transaction should be handled as a separate thread.

The program should demonstrate thread creation using both:

1. Extending the `Thread` class
2. Implementing the `Runnable` interface

Implement the following:

Create the following classes:

- `DepositThread` (extends Thread)
- `WithdrawalThread` (extends Thread)
- `BalanceCheck` (implements Runnable)
- `MiniStatement` (implements Runnable)

Each thread should display a message indicating the transaction type and the name of the thread executing it.

In the main method:

1. Create objects of all four transaction types.
2. Start all threads.
3. Allow all transactions to execute concurrently.

---

### Input Format

The program takes 4 string inputs from the user, each input must be entered line by line (one input per line):

- Name for deposit thread
- Name for withdrawal thread
- Name for balance check thread
- Name for mini statement thread

### Output Format

Display messages in the following format:

```
Deposit transaction started by <thread_name>
Withdrawal transaction started by <thread_name>
Balance check started by <thread_name>
Mini statement generated by <thread_name>
```

**Note:** the threads run concurrently, so the order of these four lines can change from run to run.

### Example

```
DepositThread1
WithdrawalThread1
BalanceCheckThread1
MiniStatementThread1

Deposit transaction started by DepositThread1
Mini statement generated by MiniStatementThread1
Balance check started by BalanceCheckThread1
Withdrawal transaction started by WithdrawalThread1
```

```
Deposit Thread A
Withdrawal Thread A
Balance Check A
Mini Statement A

Withdrawal transaction started by Withdrawal Thread A
Deposit transaction started by Deposit Thread A
Balance check started by Balance Check A
Mini statement generated by Mini Statement A
```

---

### Solution Code

```java
import java.util.Scanner;

// Way 1: create a thread by EXTENDING the Thread class
class DepositThread extends Thread {

	// Constructor receives the thread name and passes it to the Thread class constructor
	public DepositThread(String name) {
		super(name);
	}

	// run() contains the code that the thread executes after start() is called
	public void run() {
		// getName() returns the name given to this thread
		System.out.println("Deposit transaction started by " + getName());
	}
}

// Way 1 again: another thread created by extending Thread
class WithdrawalThread extends Thread {

	public WithdrawalThread(String name) {
		super(name);
	}

	public void run() {
		System.out.println("Withdrawal transaction started by " + getName());
	}
}

// Way 2: create a thread by IMPLEMENTING the Runnable interface
// (this class is only the task; it is not a Thread itself)
class BalanceCheck implements Runnable {

	public void run() {
		// BalanceCheck is not a Thread, so getName() is not available directly;
		// Thread.currentThread() gives the thread that is running this code right now
		System.out.println("Balance check started by " + Thread.currentThread().getName());
	}
}

// Way 2 again: another task using Runnable
class MiniStatement implements Runnable {

	public void run() {
		System.out.println("Mini statement generated by " + Thread.currentThread().getName());
	}
}

public class BankTransactionSystem {

	public static void main(String[] args) {

		Scanner sc = new Scanner(System.in);

		// Read the 4 thread names, one per line
		// nextLine() is used (not next()) so names with spaces like "Deposit Thread A" work
		String depositName = sc.nextLine();
		String withdrawalName = sc.nextLine();
		String balanceName = sc.nextLine();
		String miniName = sc.nextLine();

		// Threads made by extending Thread: the object itself is the thread
		DepositThread t1 = new DepositThread(depositName);
		WithdrawalThread t2 = new WithdrawalThread(withdrawalName);

		// Threads made with Runnable: wrap the task inside a Thread object
		// and give the thread its name as the second argument
		Thread t3 = new Thread(new BalanceCheck(), balanceName);
		Thread t4 = new Thread(new MiniStatement(), miniName);

		// start() creates a new thread and calls run() on it
		// (calling run() directly would NOT create a new thread)
		// all four threads now run concurrently, so the print order is not fixed
		t1.start();
		t2.start();
		t3.start();
		t4.start();

		sc.close();
	}
}
```
